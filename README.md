# Mazelet

A Java-based maze game where you navigate through a randomly generated maze, collect coins, and avoid enemies.

## How to Run

```bash
javac -d bin src/main/java/mazelet/*.java
java -cp bin mazelet.Maze
```

## Controls

- Arrow Keys: Move player
- Goal: Reach the green cell at bottom-right

## Scoring

- Start: 20 points
- Coins: +3 points
- Enemies: -5 points
